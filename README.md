# Volcano Feature Suggestion Platform

## 🚀 How to Start the Project

### 1. Backend (Flask)
The backend handles the database, API, and signal processing.
**Terminals Required:** 1

**Command:**
```powershell
# 1. Navigate to backend directory
cd d:\Valcano\backend

# 2. Activate Virtual Environment & Run
.\venv\Scripts\python.exe app.py
```
*Server will start at: `http://127.0.0.1:5000`*

---

### 2. Frontend (React/Vite)
The frontend provides the user interface for Aliens and Boardrooms.
**Terminals Required:** 1

**Command (Standard):**
```powershell
# 1. Navigate to frontend directory
cd d:\Valcano\frontend

# 2. Start Dev Server
npm run dev
```

**Command (Fallback - if npm is missing):**
```powershell
C:\Users\machi\AppData\Local\ms-playwright-go\1.50.1\node.exe d:/Valcano/frontend/node_modules/vite/bin/vite.js
```
*Server will start at: `http://localhost:5173`*
